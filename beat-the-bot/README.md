# Beat the Bot: Python for Complete Beginners

The code for the [Beat the Bot](https://www.youtube.com/@LateNiteLecturer) videos on the LateNiteLecturer channel.
You learn Python from nothing by building one game, rock, paper, scissors, and you play it against a bot that gets
cleverer every episode. Can code beat you?

Each folder holds `beat_the_bot.py` as it is **at the end of that episode**. To type along with an episode, start
from the file of the episode before it (episode 1 starts from an empty file).

## How to run it

1. Install Python from [python.org](https://www.python.org). It comes with **IDLE**, the editor used in the videos.
2. Download `beat_the_bot.py`: open it here, then use the download button at the top right of the file view.
   (Or download everything: the green *Code* button at the top of the repository, then *Download ZIP*.)
3. Open IDLE, then *File*, *Open*, and choose the file.
4. Run it with *Run*, *Run Module*, or press **F5**. The game asks for your moves in the shell window.

Every file is written one step per line, with a comment above each part, so a beginner can read it.
