# Introduction to Machine Learning with pandas

The notebooks and data for the LateNiteLecturer course of the same name. One notebook per lesson, plus
`getting_started.ipynb` for the video that comes before lesson 1. Every lesson uses the same file, `penguins.csv`.

**To follow a lesson:** download its notebook and `penguins.csv` into the same folder, open the notebook in VS Code,
select your Python kernel, and type along with the video. The "Getting started" video shows the set up.

## The data

`penguins.csv`: Palmer Penguins, 344 penguins, 8 columns. An unchanged copy of
<https://github.com/allisonhorst/palmerpenguins/blob/main/inst/extdata/penguins.csv>. `penguins_clean.csv` is the
same table with the rows that lack measurements removed (lesson 4 shows how).

Horst AM, Hill AP, Gorman KB (2020). *palmerpenguins: Palmer Archipelago (Antarctica) penguin data.*
Data collected by Dr Kristen Gorman and the Palmer Station, Antarctica LTER. Licence: CC0 1.0.
The penguin artwork in `images/` is by Allison Horst (CC0).
