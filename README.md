# LateNiteLecturer notebooks

The notebooks and data files that go with the videos on the
[LateNiteLecturer](https://www.youtube.com/@LateNiteLecturer) channel, so you can type along.

| Course | Folder |
|---|---|
| Introduction to Machine Learning with pandas | [`pandas-ml/`](pandas-ml/) |
| Beat the Bot: Python for Complete Beginners | [`beat-the-bot/`](beat-the-bot/) |

**To download one file:** open it here, then use the download button at the top right of the file view.
**To download everything:** the green *Code* button above, then *Download ZIP*.

For *Introduction to Machine Learning with pandas* you need Python and VS Code with the Jupyter extension; its
"Getting started" video shows the set up. For *Beat the Bot* you need only Python and IDLE, which comes with it:
episode 1 shows the set up.
